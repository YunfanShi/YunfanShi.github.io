# 游客与本地优先模式验证

## 行为边界

- `/dashboard`、学习、练习、工具、设置等普通工作台页面允许未登录直接访问。
- `/admin` 与 `/account-status` 仍要求登录，未登录会带 `next` 参数跳转到登录页。
- 登录页提供“游客登录”，并明确说明游客不进行跨设备云同步。
- 工作台顶部持续显示当前是游客、本地离线或云同步状态。

## 本地与云端

- 游客数据先写入浏览器本地存储；番茄钟任务与记录、QuizWise 当前题目/设置/本地历史均可离线保存。
- 登录后自动读取云端数据，并将当前设备上的非敏感学习数据合并上传。
- 删除本地条目后，同步器也会删除对应云端旧条目，避免下次登录时被重新恢复。
- 密码、API Key、访问令牌、认证信息、设备 ID、会话和诊断日志明确排除在通用同步之外。
- 旧 HTML 模块继续通过同源本地存储运行；仅登录状态下调用 Supabase 同步桥。

## 实际验证

- 未登录直接访问 `/dashboard`：通过，没有跳转到登录页。
- 游客状态提示与“登录并开启云同步”入口：通过。
- `/login?next=/study-guide` 的游客按钮保留目标地址：通过。
- 番茄钟新建测试任务、刷新页面后仍存在：通过；测试数据随后已从界面删除。
- 未登录访问 `/admin`：通过，跳转到 `/login?next=%2Fadmin`。
