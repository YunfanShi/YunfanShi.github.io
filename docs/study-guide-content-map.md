# Study Methods → Study Guide 内容映射

核对版本：2026-08-29。页面定位从“方法清单”调整为“执行中心 + 单一方法库”：执行中心只回答做什么、何时做；其他板块各自负责一种问题的具体做法。

呈现规则：每页先说明什么时候用、做到什么算完成；每个步骤都可展开查看与该内容匹配的操作、原因、例子或判断标准。不会为了格式整齐给所有步骤套同一段空泛说明。

## 状态和周期

- 单次检索：√表示独立、准确、完整；△表示部分遗漏或需要轻提示；○表示无法独立回忆或看答案才想起。
- Syllabus红绿灯：描述主题范围的长期掌握状态，不等同于一次检索结果。
- 今日进度按日期保存；本周按ISO周保存；每两周以实际完成日期为起点，14天后产生下一次留存审计。
- 周复盘日由用户自行选择，不再由周六或周日自动切换。
- 考试使用`activeExamPlan`保存考试名称、日期、类型和节奏；可开启三周计划或两周压缩计划，并在执行中心显示按剩余天数计算的当前阶段。

## 去重原则

- 日常Cue + Summary已经承担当日加工与总结，不再另加“三句总结”。
- 学校作业本身就是应用；只有证据显示不足时才额外加题。
- 每周只发现并安排2–3个最大漏洞；具体修复回到学习或习题板块。
- 每两周只审计留存和调整策略，不在该页面塞入深度专项训练。
- Anki、番茄钟和50分钟模板都是可选工具，不是必须完成的方法。
