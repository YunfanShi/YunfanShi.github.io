# JackYun TR3000 管理增强器

适用地址：`http://192.168.10.1/*`

脚本文件：`jackyun-portal/public/userscripts/tr3000-manager.user.js`

## 主要能力

- 独立设备管理侧边栏；
- 可配置的低、中、高三档上下行速率；
- 新 MAC 识别、设备基线和默认档位队列；
- 批量分级、信任标记、本地备注、复制 MAC 和解除限速待办；
- 操作说明、本地日志与配置导入导出；
- 基于可见字段填写路由器原生 QoS，不依赖未经验证的 LuCI 私有 API。

## 安全设计

1. 首次扫描只建立现有设备基线，避免把已有朋友设备误判为新设备。
2. 安全模式默认开启：脚本只打开并填写原生 QoS，不点击“保存&应用”。
3. 关闭安全模式前会明确提示实际网络影响。
4. 无法可靠识别设备、上下行字段或保存按钮时，操作只进入本地队列。
5. “解除限速”不把 `0` 猜成无限速，而是打开原生 QoS 供人工删除或停用规则。
6. 不保存路由器密码，不向互联网发送 MAC、IP、备注、配置或日志。

## 推荐验证顺序

1. 安装脚本并打开 TR3000 的“网络设备”页面。
2. 确认设备数量与原页面一致，并建立现有设备基线。
3. 设置三档速率，保持安全模式开启。
4. 选择一台非管理设备，点击“低配额”。
5. 检查原生表单中的 MAC、下载、上传和备注，人工保存。
6. 实测限速与解除限速后，再开启新设备自动处理。
7. 只有确认当前固件字段稳定后，才考虑关闭安全模式。

## 固件兼容边界

脚本根据可见的 MAC、私网 IP、按钮文字和表单标签进行识别。固件升级、语言变化或页面结构调整可能使自动填表失效；失效时脚本应保留队列而不直接发送配置。应更新页面适配器，而不是调用抓包得到的私有接口。
