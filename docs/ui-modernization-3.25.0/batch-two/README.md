## 交互与主题改造

Sidebar 改用共享 Button 和 Input，导航颜色取站内变量，避免系统 dark 样式覆盖站内浅色主题。保留原有导航顺序、隐藏、固定、折叠、变体及访问条件。导航偏好从本机读取完成前不写入默认值；沿用 coerceNavigationPreferences 规范化现有格式。

导航等待状态在路径切换后清理，避免浏览器返回时旧等待提示再次出现。预取继续调用 Next.js router.prefetch，新增策略只限制可选意图预取：离线、节省流量、2G 和用户关闭预取时不触发；管理员、BETA、featureKey 入口不预取；游客只允许公开只读入口。服务器权限控制继续生效。

Topbar 的更多操作改为 Radix DropdownMenu，支持方向键、Home、End、Escape 和焦点恢复。手机抽屉或菜单打开期间，全局导航快捷键不穿透。主题按钮监听根节点 data-theme，云端设置或其他组件改变主题后，按钮的下一主题标签同步更新；三主题及原 iframe 通知机制保留。

全屏帮助改用共享 Dialog。浏览器回归发现把帮助挂在菜单内部会随菜单关闭而卸载，现已将其独立挂载，用窄范围 imperative ref 传递触发动作。Portal 依据主题与 fullscreen 容器选择，不创建第二套主题系统。

退出弹窗保留原备份、同步等待、离线待提交检查、普通及强制退出业务。增加即时防重复提交、保存中禁止关闭和失败保留提示。手机触发时使用菜单所在 Portal 容器，并将焦点还给可见触发器。登录专项使用本机签名 fixture 验证普通用户退出失败、保留本地数据、取消重试，以及手机和桌面焦点恢复；真实 Supabase Auth 及 RLS 仍待预览环境验证。

## 首页与通知实现

首页工作台入口调整到学习概览之前。学习概览提取为 async Server Component，通过 Suspense 独立返回；入口不再等待八项概览查询完成。认证读取仍保留，概览查询继续 Promise.all，并未重写缓存、Router 或数据接口。等待区域明确说明统计和任务未加载完成，不能把它计入可用内容耗时。

ProductCard 保留 Next Link 和原业务路由，采用统一焦点、边框及品牌状态，移除整卡位移与图标放大。首页继续学习入口采用共享 Button。此项不作为性能达标证据，生产环境下的加载与交互指标仍需测量。

通知入口、通知列表和消息详情改用共享 Dialog。历史请求仍仅在用户打开历史时发生；加载中、空列表、失败和重试分开显示。失败保留已加载内容，关闭中止请求，返回数据继续核对 userId。详情 Markdown 和客服会话继续沿用原按需加载组件。

一键已读使用即时 ref 防重，错误路径恢复忙碌状态并保留通知；单条标记失败给出可重试反馈。仍调用原 dismissNotification 与 dismissNotifications，只在成功后发布原 notification-dismissed 事件。没有修改通知投递和存储协议。

顶栏按 user.id 为通知组件设置实例边界，账号改变时不保留上一账号的已选消息。登录 fixture 已覆盖账号角色导航、历史取消/失败/重试、已读重复请求、详情焦点、退出失败与重试。真实云端迟到响应、分页、多设备账号隔离仍待预览环境验证。客服会话原有复杂交互列入第三批，未因外层换 Dialog 而算完成。

## 验证结果与继续工作

2026-10-21 在 `feat/ui-modernization-shell` 完成第二批生产模式验证。Next.js 16.3.8 `next build --webpack` 通过；TypeScript、改动文件 scoped ESLint、`git diff --check`、私钥标记检查通过。39 项 Node 回归通过，包含现有同步、离线、晚回执、计时恢复和 IELTS 并发测试，以及 3 项预取策略测试。构建与本机 fixture 均使用占位 Supabase URL/匿名 key，不接入真实用户或云数据。

Edge headless + standalone 生产服务下，主导航和弹层测试覆盖 320、390、768、1440 四种视口，旧移动导航覆盖 320×568、390×844、430×932、844×390 和 1440×900；第一批工具箱 10 组生产流程通过，覆盖草稿、真实 DOCX 导出和冷离线失败后重试。登录专项通过 7 组流程：角色导航/直接访问权限、通知历史加载与取消、失败保留和重试、Server Action 防重复已读、详情焦点恢复、桌面/手机退出失败保留本地状态。首页统计接口配置 1.8 秒延迟时，工作台入口在 129 ms 可用；这是本机局部流程测量，不代表网络端到端性能。

通知 Dialog 单独采集 30 个热态样本，测量从点击到内容可见并经过两次 `requestAnimationFrame`，P95 为 40 ms，未包含网络。结果低于本地弹窗建议阈值 200 ms；仅代表 Edge headless、当前电脑与已经加载页面下的本机操作，不代表手机真机或线上用户 P95。批次间整体页面切换改善仍需以真实用户路径和生产数据复测。

占位后端会产生原有 JY-5002 错误提示，提示可能挡住测试点击。测试通过用户可见的关闭错误提示按钮关闭后继续；没有隐藏错误层、强制点击或删除业务断言。工具箱冷离线流程同样通过实际关闭按钮处理预期网络提示，再验证面板重试。

未验证范围：真实 Supabase 登录/RLS、线上管理员与权益矩阵、生产部署预览、GitHub Actions 远端运行结果、Android/iOS 真机、低端设备与弱网、云端通知迟到响应和真实多设备接续、PWA 升降级及数据回退演练。CI 已增加本机 fixture 登录专项、启动健康检查和浏览器产物上传，但尚未由远程 GitHub Actions 执行。全站业务页、旧 iframe 和集成发布仍属于第三至第五批。

第二批本机验收已完成，仍需形成独立提交边界与远程 PR 审查；在用户审查之前不合并。接着按在用页面清单完成第三批业务、第四批 iframe 兼容和第五批集成验证。任何 UI 回退均只回退代码，不清空本机数据、不回滚用户记录；所有同步与数据契约维持现状。
