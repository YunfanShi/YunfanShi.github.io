# CUE 宇宙冒险

在“设置 → 学习与专注”开启“CUE 宇宙冒险”，点击保存设置。默认关闭；日程的设置页也有直达链接。

开启后，CUE 学习页和含 CUE 的统一学习页显示星空战斗、经验条、等级及飞船收藏。每条 CUE 每个本地日历日的首次复习获得 10 XP；√ / △ / ○ 奖励相同。重复评价、重复会话和重复同步记录不会重复计分。每 5 条击败一个敌人，每 100 XP 升一级；等级 1、3、5、10 解锁飞船外观。经验包含已有复习历史，由保存的复习记录重建，关闭显示不会删除记录。等级表示复习投入，不表示知识掌握程度。

新 CUE 学习默认乱序。关闭“CUE 默认乱序”并保存后，新学习按原顺序开始；学习入口和学习中也可切换本轮顺序。恢复已有会话保留顺序、位置和评价。统一学习继续按 CUE 与关联题目组织，题目练习顺序不受纯 CUE 乱序设置影响。

战斗反馈不会阻塞答题。学习页的动效开关、外观设置的“减少动态效果”以及系统减少动态效果偏好均可减少动画。

验证：`npm run test:learning` 包含经验去重、默认设置、跨日奖励、等级边界、飞船解锁、顺序恢复和战斗组件可访问性检查。
