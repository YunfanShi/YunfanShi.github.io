# 题库与统一学习

入口：`/schedule` → **学习**、**题库**。

## 使用

- 在题库的“学习目录”配置科目和单元，然后新增题目，或批量导入。
- 题型：单选、多选、判断、主观题。答案可以为空；主观题与纸上作答由用户对照答案和评分点自评。
- 学习支持知识 CUE、题目、统一学习。先选科目、单元和筛选范围，检查队列及预计时长后开始。
- 统一学习按选中内容的关联组织；多 CUE 关联题在相关 CUE 之后出现。未选中的关联 CUE 只提供查看入口。
- 客观题正确性与 √ / △ / ○ 独立记录。得分、满分、错因均可选。修改得分或错因后再次点击评价更新记录。
- 退出即保留作答与评价进度，刷新后可继续。旧版 CUE 草稿通过“兼容旧 CUE 学习进度”恢复。
- “从知识 CUE 复制”先展示映射和编辑预览；原 CUE、原历史不变，新题目从首次练习开始记录。

## 导入导出

界面提供带真实科目 ID 的示例、科目/CUE ID 列表与变更预览。

```json
{
  "version": 1,
  "operations": [
    {
      "action": "create",
      "question": {
        "subjectId": "使用学习目录中的真实 ID",
        "subjectName": "使用学习目录中的真实名称",
        "unit": "Unit 1",
        "type": "single",
        "prompt": "填写题干",
        "choices": ["A", "B"],
        "correctChoices": [0],
        "answer": "",
        "explanation": "",
        "markingPoints": [],
        "linkedCueIds": []
      }
    },
    { "action": "update", "id": "已有题目真实 ID", "changes": { "answer": "修订答案" } }
  ]
}
```

`type` 为 `single` / `multiple` / `boolean` / `written`；`correctChoices` 使用零起始索引，留空表示自评。`boolean` 选项为“正确”“错误”。更新只修改提供的字段。支持可选 `subsection`、`source`、`number`、`maxScore`、`sourceCueId`。

“复制当前题目”保留 ID，适合增量修改；“导出当前题目”生成创建操作，导入会创建新题目，不携带历史。

## 数据与兼容

- CUE 继续使用 `jackyun_schedule_control_v1`。题库、题目复习历史与统一学习草稿独立存于 `jackyun_schedule_questions_v1`（schemaVersion 1）。
- 队列以 `{ kind: 'cue' | 'question', id }` 引用内容；相同 ID 不会串写。
- 作答提交时保存题目版本与快照；评价立即持久化，同一会话/题目重复评价更新同一条记录。
- 完成会话将题目证据写入现有学习记录，通过会话 ID 去重；题目评价不修改关联 CUE 的状态。
- 删除题目后移除队列引用，已保存的作答快照保留。不能识别的题库数据会报错并保留原值，不用空题库覆盖。
- 题库通过现有同步 outbox、冲突合并和大值分片传输同步。归入备份中心的 **Schedule 与课表**，包含题库、作答与草稿。旧“Schedule 主数据版本”只包含原 Schedule 主键；题库恢复使用备份中心。
- 两类自动复习共用现有日容量：繁忙日最多 1 个批次，其他日最多 2 个；题目每批最多 6 题。先选择内容，再按知识关联排序。当天评价过的内容不再自动安排，可手动重练。

无新数据库表或迁移。现有 Quiz 保持独立；它的 AI 判分和按会话保存的数据不参与题库学习。现有 Quiz 判题接受文本标签，新题库使用选项索引集合，采用独立的确定性集合比较，避免歧义与 AI 依赖。

## 2026-09-27 学习体验更新

- 知识 CUE 专项学习与未完成进度卡片直接展开。题目 / 统一学习也提供科目概览，显示到期、薄弱、未练习数量。
- 关联 CUE 任务点击完成直接进入检索，学习评价自动形成证据；文字、错因、得分与备注均可留空。普通任务补充文字默认收起。
- 每道题自动获得固定短编号，如 `PH-K2Z1`：前两位来自创建时的科目名称，后四位为身份码。科目或内容编辑不会改号；原书题号独立保留。按短编号、来源、原书题号搜索。旧题无来源时显示“来源待补充”，不虚构出处。
- 编辑器支持 PNG / JPEG / WebP 上传，每张最多 2 MB、每题最多 6 张，可分为题干图或答案图。图片内嵌题目记录，共同参与云同步、大数据传输及备份；答案图在揭示答案之后显示。作答快照保留当时图片。图片多时数据体积与本机存储占用会增加，保存失败时明确报错。
- 稳定项基础间隔 3、6、9、12、15、18 天；难度系数：简单 1.5、中等 1、难 0.75、极限 0.5，结果仍限制为 1–18 天。历史失误权重和实际跨天检索优先；△ / ○ 1 天后修复，提前重复不扩大间隔。旧计划通过历史重算迁移。
- 登录后导入 / 修改 CUE 会自动通过既有 AI 配置辅助评级；响应需通过真实 ID、枚举、完整性与容量校验。AI 失败时继续使用代码规则，可在学习记录页重试。内容签名不符的过期建议无效，用户难度覆盖 AI；最近五次中跨三天反复失误会临时提高有效难度。难度建议与用户覆盖共同同步备份。
- 练习中可看见并修改难度。学习记录页显示按学科与题型统计的真实 △ / ○ 比例；AI 接收这些汇总及当前批次最近八次证据，辅助指出薄弱类型和提示质量问题。不把统计解释为永久能力标签。
- AI 可在 1–2 批内建议当天容量，但不得突破现有繁忙日上限；达到 18 天的内容优先排入队列，忽略缩减容量建议。18 天是排期上限；如果用户不学习或到期量超过容量，实际检索仍可能逾期，内容保留在到期队列，不会永久停止复习。
- AI 提示改写仅为预览建议，点击“采用提示修改”才改现有 CUE，保留历史。对于只给陌生术语、需查看评分点才能作答的提示，应明确检索动作或采用可直接作答的运算任务，不能把所考答案放进题干。

验证分开报告：自动化算法 / 存储 / 同步测试、浏览器 UI 验证、真实账户的 AI 调用与跨设备同步恢复。前两项通过并不代表已完成第三项。

AI 每天首次进入日程时更新当天容量建议，即使没有待评级的 CUE；输入只使用课程数量、未完成任务时长和真实近期评价。AI 可辅助标注 Definition / Calculate 等能力维度；过期标注不参与画像。达到 18 天的题目也受同一容量保护。

本次验证：101 项学习测试、29 项同步测试、修改范围 ESLint、生产构建和 TypeScript 检查；本地浏览器核对旧概览、短编号及来源搜索、真实图片上传与加载、手动难度调整、390×844 手机图片作答页面及零控制台错误。未使用真实账户测试 AI 提供方或跨设备图片恢复。


### CUE 难度自动分析与信息入口

旧 CUE 无评级、新增或内容修改后的 CUE，在登录后自动批量分析，无须逐条确认。评级作为调度输入直接生效；用户成果仍决定实际复习间隔，△ / ○ 优先修复，稳定内容按难度系数调节，最长 18 天。新增三个不同日期的练习证据后，后台会重新分析，网站规则在每次评价时立即生效。AI 不可用时继续使用现有代码规则。

完整 AI 评级、理由、提示质量、分析时间和用户覆盖入口放在 CUE 管理的「详细信息」。学习过程中默认仅显示可展开的「CUE 信息」入口，不逐条播报分析完成。界面显示实际采用的难度系数（简单 1.50、中等 1.00、难 0.75、极限 0.50），并与历史 easeFactor 参数区分。修改用户评级立即重算未来排期，保留原学习记录。


## 提示词、表现图与新手介绍

CUE 批量导入与题库导入统一提供两个内容导出操作：**导出当前数据**下载当前筛选范围的编辑 JSON（保留真实 ID，用于修改现有内容）；**复制提示词及数据**携带规则、目录、格式和当前内容，附上笔记交给 AI。完整历史、进度与媒体恢复继续使用账户同步/备份；这两个内容操作不取代备份。复制给 AI 的题库数据仅包含已有图片定位信息，不包含图片 base64。

CUE RULES v2 保留当前笔记进度、老师 DEF 准确措辞、考试核心覆盖、一个知识点先一个主 CUE、真实 ID 更新、create 不写 subsection 和 200 操作上限。补充独立可作答任务、陌生术语澄清、条件齐全、避免题干泄露答案和评分点匹配检查。知识检索与完整练习题分别管理。

题库 JSON 可用 `imageRequests: [{"id":"fig1","description":"需要补的图及特征","source":"教材页码/题号","placement":"prompt"}]` 标记缺图；答案图使用 `answer`。每题最多 6 个请求，ID 唯一。导入后在题库编辑页按说明从本地上传图片，再将请求关联到对应位置的真实图片。移除或改图片位置会恢复待补图。AI 不生成虚假 URL、base64 或缺图数值；缺图学习页显示提示，可以跳过。上传媒体沿用题库同步与备份，登录后的同步成功状态才代表云端已保存；真实账号跨设备往返仍需实际验证。

学习记录新增默认按学科的 √/△/○ 堆叠表现图，可选学科并切换 Unit、CUE type、知识能力、题型、错因。按全部历史练习次数统计，重复练习计入；客观答对率只使用有标准答案且已核对的题目，区别于稳定自评。CUE 用当前分类，题目用作答快照。已删除且不能识别的 CUE 不计入；错因仅采用题目里用户明确填写的内容，不根据 CUE 备注猜测。没有数据的维度显示空状态。

个性化 AI 报告由用户主动生成，依据代码统计与时间范围，最多传送每维度 80 组（薄弱度优先，长标签截断），不传图片或原始作答全文。报告按学科保留最新一份，最多 20 份，随 Schedule 同步/备份；数据改变会提示重新生成。报告是辅助建议，不修改状态、成绩或安排。

Schedule 首次打开显示五步教程（今天、独立管理、提示词导入、学习评价、表现图），完成或跳过后记住版本，设置可重新打开。使用原生 modal dialog 支持键盘焦点限制及 Escape 关闭。


## CUE 评级管理与连接提示

学习记录页的「AI 辅助复习 · 打开评级管理」打开模态弹窗，默认不常驻列表。弹窗统计待评级/更新、排队/正在处理、已评级、失败；支持学科、状态与文本筛选、查看最新 AI 评级时间/本次请求时间、单条和当前范围/所选批量重评、停止本轮和恢复。评级详情可查看理由、质量建议、系统采用系数及修改用户评级。

请求阶段明确区分未发送排队、发起请求、等待响应、读取结果、校验、已保存、失败及停止/内容变化后的旧响应丢弃。每次最多十条顺序分批，防止同一 CUE 重复排队和并发重复提交；不声称知道 AI 服务内部进度。每批超时 90 秒。失败保留旧结果并暂停后续队列，用户可重试或恢复；关闭弹窗继续后台处理，离开 Schedule 则取消未完成请求。结果/最新评级时间随 CUE 同步和备份，实时请求阶段在当前页面内有效，不作为跨设备任务状态。

全站日志继续捕获请求失败，但不再把任意请求失败升级为全局服务故障。全局横幅只依据实际同步任务：前两次暂时性连接失败保持“待同步”，第三次连续失败才显示，离线仅显示待同步，成功同步后清除。对应功能内的错误仍保留。关闭提示隐藏当前故障阶段，成功后新的连续故障可以再显示；「关闭 10 分钟」在当前标签页跨导航/刷新生效，只隐藏横幅，不停止重试、不清除待同步修改，也不把失败改成成功。

验证包括真实组件使用本地模拟 AI 响应和同步事件：排队/等待、批量更新、失败保留旧结果、恢复、停止、一/三次失败边界、成功消除、十分钟静音重复失败、手机 390px 无横向溢出。模拟页在发布前删除；真实账户 AI 及地铁网络/跨设备同步恢复不在自动测试的证明范围内。

### 评级校验恢复与实时任务视图

- 评级弹窗默认显示当前任务，按正在请求、失败、排队、待处理、本页完成排序；显示请求阶段和等待秒数。全部历史评级、筛选和批量操作在“全部评级 / 批量管理”中查看。
- 能力维度与 CUE 类型使用同一组可选枚举。AI 返回未知或格式错误的可选能力维度时，忽略该字段并在 CUE 信息中注明，按原类型统计；有效难度评级仍保存。ID、重复结果、难度、内容版本及批次完整性继续严格校验。
- 回归复现覆盖一条未知能力维度导致十条批次失败的旧问题，验证未知字符串、null、数值及对象不会再拖累有效批次。用户日志仅含请求状态，不能据此还原模型实际返回的维度名称。

### AI 回复与错误诊断

- 客户端日志记录结构化 AI HTTP 响应（凭据与隐藏推理已脱敏）、可见回复、结束原因及使用量，长回复分段记录，每个响应最多保留 100,000 字符并标记截断。CUE 请求、解析、校验和保存共用诊断编号，失败行也显示编号。
- JSON 解析、AI 响应读取及流读取失败进入错误日志；捕获的同步错误、非成功 HTTP 错误响应及页面资源加载失败也记录。既有 console、未捕获异常、Promise 拒绝和页面错误边界仍记录。应用主动捕获的其他业务错误仍需要各业务入口显式报告，不声称能自动捕获 JavaScript 中所有 catch。
- “复制日志”包括 Data 和 Stack，JSON 导出与查看包含刷新前的本地记录。内存最多 1000 条，本地最多 500 条且受 1 MiB 容量限制；清空日志同时清空待持久化条目。日志留在本机，反馈附件沿用用户主动提交流程。
